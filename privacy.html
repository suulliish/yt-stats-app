Privacy Policy

Last updated: November 8, 2026

YT Stats App is a personal tool used only by its owner to view statistics of the owner's own YouTube channels.

Data accessed

With the user's permission, the app reads YouTube channel statistics and YouTube Analytics reports (read-only scopes). It does not access any other Google data.

How data is used

Data is used only to display statistics to the channel owner. It is stored only on the owner's own computer, is not sold, shared or transferred to any third party, and is not used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
